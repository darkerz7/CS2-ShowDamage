# CS2-ShowDamage
Shows the damage dealt to the player

## Required packages:
1. [CounterStrikeSharp](https://github.com/roflmuffin/CounterStrikeSharp/)
2. [CS2-GameHUD](https://github.com/darkerz7/CS2-GameHUD/)
3. Optional [CS2-PlayerSettingsNext](https://github.com/darkerz7/CS2-PlayerSettingsNext)

## Installation:
1. Install CS2-GameHUD, optional CS2-PlayerSettingsNext
2. Compile or copy CS2-ShowDamage to `counterstrikesharp/plugins/CS2-ShowDamage` folger
3. Restart server
